# Prompts utilizados

1. Ayúdame a crear paso a paso una aplicación web para reservas de una biblioteca utilizando Node.js, Sequelize, React y sesiones mediante cookies.

2. Ayúdame a definir la estructura del proyecto y los modelos necesarios para usuarios, salas y reservas.

3. Ayúdame a conectar Sequelize con SQL Server.

4. Ayúdame a crear el login utilizando cookies y sesiones con expiración de 30 minutos por inactividad.

5. Ayúdame a crear una ruta protegida para listar salas.

6. Ayúdame a crear reservas y evitar que una sala tenga horarios solapados.

7. Ayúdame a crear el frontend básico en React para iniciar sesión, listar salas y crear reservas.

8. Ayúdame a hacer que el frontend redirija al login cuando el backend responda con código 401.

9. Ayúdame a corregir errores encontrados durante la ejecución del backend y frontend.
